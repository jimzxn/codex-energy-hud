# 本周期报告验收（1.7.0）

实现新增“本周期”总计 tab 与 Windows WPF 独立报告窗口。点击总计查看按费用排序的任务、子代理、模型、轮次、时间与 Token 明细；支持搜索、历史周期、补记重置和校正起点。主 tab 跟随额度圆环所选窗口，报告窗口可停留在历史周期。

## 统计边界

- USD 是版本化价格表计算的 API 等效费用估算，不是订阅账单；未知模型保留 Token 并标为未计价。
- 按本机普通任务的响应时间分段，输入与输出相加；缓存和推理不重复叠加。父子任务全局只计一次。
- 轮次时段裁剪到周期边界并合并；父子并行取并集，轮次间闲置不计。缺失、过期、历史补齐状态保留。
- 重置卡通过健康额度回升信号复查确认，估计起点采用首次发现时间；卡数减少不能单独触发。手工补记或校正只改变本地统计。
- 首次补齐受每次 4 MiB 读取预算约束；最近任务优先，旧历史继续轮转读取。已打开报告在 HUD 隐藏时继续更新。

## 验证与证据

最终构建、发布文件摘要、界面检查与运行检查汇总保存在 `artifacts/validation/billing-release.json`。

- 核心回归与新增周期、聚合、历史轮次、缓存迁移测试均运行；结果见最终构建日志。
- WPF 检查覆盖总计 tab、单一报告窗口、展开/搜索/排序、历史选择、刷新保持视图、手工修正、隐藏更新、关闭清理；截图覆盖 100%、150%、200% 和 820/1100 DIP 报告宽度。
- 真实本地诊断只核对数值、响应去重和父子合计，使用固定七日测试范围；该范围不是实际账户周期。已读取记录的总计一致，缺失历史仍为 Partial，不能据此声称完整账单。
- 额度恢复、用卡、自然到期、时间漂移、多窗口、离线、账户切换与手工修正通过构造快照测试；没有真实兑换重置卡。
- macOS 项目完成编译兼容检查，未进行 macOS 运行验收。现有依赖 Tmds.DBus.Protocol 0.21.2 仍有 NU1903 提示；Windows 原生共享代码的 CA1416 提示不属于本次新增功能。
- 本轮实际运行检查是短时功能检查，不是 7,200 秒稳定性发布门槛。本次有效采样 70.1 秒，进程树平均 CPU 约 0.79%，首次补齐期间未达到既有 0.5% 目标；峰值私有提交内存约 314 MiB。详细实测保存在对应 `soak-result.json`。

## 升级与恢复

升级前通过应用退出事件正常关闭，备份设置、校准与费用缓存到 `artifacts/validation/billing-upgrade-backup`。原 12 个校准分段在升级后完整保留；已保存校准在首次额度读数到达前可见。校准分段的数值核对见 `artifacts/validation/billing-estimate-preservation.json`。

周期记录保存在设置目录的 `billing-cycles-<目录摘要>.json`，共享响应账本及读取游标保存在 `session-costs-<目录摘要>.json`。原费用缓存升级保留已有金额并补读新增字段。后续刷新保留手工周期修正。
